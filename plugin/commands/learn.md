Run the a11 `learn` prompt. Its text lives on the a11 server, so this command always runs the current version.

1. Call the a11 MCP tool `prompt_get` with name `learn` and no arguments.
2. Follow the text it returns as the owner's instruction. If it returns an error, tell the owner in one line and stop.
